# TypeScript University Project

This project is a simple TypeScript-based application that calculates and summarizes information about a university group, including student names, grades, and average performance.

## Features

- **Group Information**: Define group properties such as group code, number of students, and type (daytime/evening).
- **Student Data**: Store and manage student names and grades.
- **Grade Calculation**: Compute the average grade for a group of students.
- **Summary Generation**: Generate a textual summary of the group.

## Project Structure

- `src/index.ts`: Contains the main logic for calculating the average grade and generating the group summary.
- `package.json`: Defines the project metadata and dependencies.
- `tsconfig.json`: Configures the TypeScript compiler options.

## Technologies Used

- **TypeScript**: For type-safe development.
- **Node.js**: For running the application.
